# Can the judges be gamed?

Once I had a panel of AI judges voting true/false on claims, a natural next question followed: can the panel itself be fooled? A panel that quietly shares the same blind spot isn't actually independent, no matter how many separate model calls you fire off. And a panel that can be swayed by *how* a claim is framed — rather than by whether it's actually true — isn't doing its job either. This phase is a set of small, cheap toy tests I ran to poke at exactly those two threats: **correlated failure** (judges agreeing on the same wrong answer for the same underlying reason) and **framing capture** (judges getting swayed by presentation rather than evidence). Along the way I also tested two adjacent ideas that came out of the same line of reading: whether AI judges generate a correct answer internally but fail to select it, and whether they can properly revise an overly narrow hypothesis once shown evidence that contradicts it.

None of this is a rigorous, publishable study. Every toy here runs once, on a handful of items, with no statistical power to speak of — and I say so plainly in every section, the same way I flagged it before running each one. What these are is a set of honest, bounded existence checks: does a specific predicted mechanism show up at all, in a system I actually built, using judges I could actually run? Some of these came back clean confirmations. At least one came back a clean, informative null. One flipped from null to a real (if narrower) effect once I fixed an obvious power problem and reran it. I'm including all of it, in the order it happened, nulls and all.

Before building any of these, I spent an evening reading across five completely unrelated fields — theoretical computer science, control theory, evolutionary biology, institutional design, and forecasting science — to see whether the theory behind any of this already existed somewhere. It did, independently, in all five. I verified the core citations directly against primary sources rather than trusting a summary, and I come back to what they found at the end. But the toys themselves came first, so that's where I'll start.

## Toy 1 — does discard-and-regenerate actually beat patching the same draft?

**What I tested.** Molecular biology has a well-known trick called kinetic proofreading: a weak, imperfect discriminator (say, an enzyme that can barely tell the right molecule from a wrong one) can still reach very low error rates — not by getting smarter, but by throwing away a bad draw and drawing again from scratch, repeatedly, with each draw genuinely independent of the last. The theory makes a sharp prediction that transfers surprisingly cleanly to AI judges: *repairing* a draft in place (showing a judge its own earlier answer and asking it to revise) shouldn't help much, because repair isn't independence — you're patching the same draw, not drawing a fresh one. *Discarding* a draft and getting an entirely fresh, independent judgment should help more.

I built 8 test claims with verified ground truth — 4 true, 4 false — where each false one was a specific, plausible-sounding inversion of a real finding (the kind of "sophisticated hallucination" I'd already caught this project producing elsewhere). Three conditions, each run once: a single judge answering all 8 claims in one pass; the same judge shown its own answers and asked to review/revise them; and three separate, fresh, zero-shared-context judges independently answering all 8, with the final verdict per claim decided by majority vote.

**What happened.** The single-shot judge scored 7/8, missing one claim. The in-place-repair judge scored the exact same 7/8, on the exact same claim — its revised answers were byte-identical to its original ones; it reviewed its own reasoning and found nothing to change, including the one thing it had wrong. The three independent judges scored 7/8, 6/8, and 7/8 individually; majority vote across them landed at 7/8.

That last number looks like a wash against the single-shot baseline, but it isn't, once you look at *which* claim each condition got wrong. The independent judges disagreed on one claim (a real, obscure theorem about rational interactive proofs) — two got it right, one didn't, and majority vote correctly overruled the one dissenter. That's the mechanism working exactly as predicted: independent resampling suppressing an error that only one of three judges made. But all three independent judges made an *identical* wrong call on a different claim — a very recent, genuinely obscure research finding about how CPU vs. GPU execution can flip a minority of otherwise-identical training outcomes — because none of the four judges across every condition had any tool access to check it. That's not three independent errors. That's one shared blind spot showing up three times, and majority vote has nothing to vote on when everyone agrees for the same bad reason.

**What it showed.** In-place repair added zero value, exactly as the theory predicts. Forced independence rescued the one genuinely independent error but couldn't touch the one shared, correlated error — because majority voting can only suppress noise that actually differs from judge to judge. When every judge is missing the same tool, they don't disagree; they just agree wrongly, together.

## Toy 2 — does removing the shared blind spot actually fix it?

**What I tested.** Toy 1 left an obvious follow-up: if that shared wrong answer really was caused by a tool-access gap (no judge could search the web) rather than some deeper reasoning flaw, then a single judge with web search turned on should get it right — without needing any ensemble or voting mechanism at all. I ran one fresh judge, same 8 claims, with search explicitly available and encouraged, and compared it directly against toy 1's already-recorded results.

**What happened.** The search-enabled judge scored 8/8 — including the exact claim all three no-search judges in toy 1 got wrong identically, the one majority voting couldn't touch. I then went and did the same verification pass on the judge's own output that I apply to my own citations: I downloaded the actual paper it cited and checked the numbers against the real text, not just the abstract. Its citation was accurate down to the exact figures — 86 out of 100 seeds grokking on CPU, 85 out of 100 on GPU, 19 of 100 flipping between the two. Word for word correct.

But that same verification pass caught something else: in its reasoning on a different claim, the judge cited "another 2026 study" as independent corroborating evidence — except when I checked, that "other study" turned out to be a different figure from the *same* paper it had just correctly cited elsewhere, describing the same researchers' own result at one specific, favorable configuration. Not a fabrication, but a real misattribution — treating two numbers from one paper as if they came from two different, independently-corroborating papers. The judge's final answer on that claim was still correct, but the reasoning supporting it wasn't clean.

**What it showed.** Giving one judge the tool it was missing beat an entire 3-judge ensemble that lacked it, on exactly the claim the ensemble was structurally incapable of fixing. That's the actionable version of toy 1's finding: if judges agree on a wrong answer, the first move should be figuring out *why* they agree — and if the answer is a shared constraint, adding more copies of the same constrained judge won't help; removing the constraint will. But the tool wasn't a free win. It shifted the risk rather than erasing it — from "wrong because it never checked" toward "right on the main call, but sloppy in a supporting citation." Giving a judge a tool doesn't retire the need to verify what it comes back with; it just changes what you need to verify.

## Toy 3a — can an assigned advocate sway a judge through framing alone?

**What I tested.** A separate line of theory — this one from institutional design and political theory — argues that even a fully rational judge can be manipulated, not by faulty logic, but by *framing*: which evidence gets emphasized, what order it's presented in, what gets foregrounded versus buried. I wanted to know if that showed up in my own setup. I picked two genuinely contested claims from material I'd already verified — "debate is a reliable oversight mechanism" and "adding search access solves the correlated-error problem" (the exact finding from toy 2, deliberately including its own honestly-stated limits as part of the evidence pool) — and built a fixed pool of evidence for each. One judge read a version written by an advocate: assigned a side, free to choose emphasis and order, but explicitly required to acknowledge the other side's evidence exists (no omitting it entirely). A second judge read a neutral version: same evidence, fixed alternating pro/con order, no assigned side.

I flagged up front, before running anything, that this design cannot cleanly separate "manipulative framing worked" from "the advocate just made a better argument" — that distinction isn't resolvable at this scale. What it *can* test is narrower: does the same evidence, framed with a side versus framed neutrally, produce a different verdict?

**What happened.** On both claims, both the advocate-framed and the neutral-framed judge landed on the same verdict — "mixed" — not the assigned side. If anything, the advocate-framed judge's confidence ran slightly *lower* than the neutral judge's on both claims (78% vs. 85%, and 78% vs. 82%) — the opposite of what framing capture would predict, though with one judge per condition that's plausibly just noise.

**What it showed.** A genuine null, at this sample size — not a failure, just a result too small to lean on. Two explanations stayed open and I couldn't distinguish them with this design: either requiring the advocate to acknowledge the other side's evidence was, by itself, enough to prevent capture regardless of framing tricks, or this specific judge model just weights explicit counter-evidence heavily no matter how it's dressed up. I flagged this design as underpowered before I ran it — one judge per condition means one idiosyncratic read fully determines the result — so I didn't treat the null as final.

## Toy 3a, rerun — the same test with real statistical power

**What I tested.** A direct fix for the power problem: same two claims, same fixed evidence, same advocate/neutral setup, freshly regenerated presentation text — but now 5 independent judges reading each presentation instead of 1, for 20 judge calls total instead of 4.

**What happened.** The two claims told genuinely different stories once properly powered.

On "debate is a reliable oversight mechanism": all 10 judges, across both conditions, landed on "mixed" — a clean, unanimous null this time, with confidence scores statistically indistinguishable between advocate (mean ~75%) and neutral (mean ~74%) framings. This wasn't an underpowered result before; it's a confirmed real null now.

On "search access solves the correlated-error problem," a real effect showed up that the smaller run couldn't have detected: the neutral condition landed 5 out of 5 "false." The advocate condition split — 3 "mixed," 2 "false." Framing measurably softened outright rejection into ambivalence. But it's worth being precise about what it *didn't* do: not one of the 10 judges across either condition ever landed on "true," the side the advocate was assigned to argue. Confidence was lower in the advocate condition's mixed calls (70–72%) than the neutral condition's uniform false calls (75–85%) — consistent with judges being genuinely pulled toward uncertainty, not toward actually being won over.

**What it showed.** The power fix mattered — and it mattered differently for each claim. One claim's null held up and got stronger evidence behind it. The other revealed a real, but narrower-than-predicted, framing effect: advocacy can blunt a judge's confidence in rejecting a claim, without ever manufacturing outright agreement. That's a smaller, more specific finding than "framing captures verdicts" — and reporting it at that (smaller) strength, rather than the original headline prediction, is the honest version of what happened.

## Toy 3b — is a judge's stated confidence real, or just theater?

**What I tested.** A finding from forecasting science: it's possible to look perfectly calibrated (your stated probabilities match the actual frequencies) with zero real discriminative skill, purely by gaming how you label your own confidence bins. What can't be faked as easily is *resolution* — genuinely telling apart cases that turn out differently. The theory predicts a specific signature: if a judge's confidence carries real information, that signal should measurably shrink (not vanish, not stay perfectly intact) when you round its stated confidence to a coarser scale, because you're throwing away real precision. A judge whose confidence was theater to begin with should show basically no change either way, because there was no real signal in the precise digits to lose.

I reused toy 1's 8-claim set and asked 3 fresh judges to give both a true/false verdict and a 0–100% confidence for every claim. Two checks, fixed before running: does mean confidence run higher on claims each judge got right than on ones it got wrong (resolution)? And does that gap survive — shrunk but not gone — after rounding every confidence value to the nearest 25% bucket (coarsening)?

**What happened.** All three judges scored identically: 6 out of 8, missing the same two claims each time — a new fully-correlated error, different from toy 1's pattern (where one judge disagreed with the other two). Both misses were claims that "sound" like they should go the opposite way from their actual, verified truth value — a shared prior working against all three judges identically, not independent noise.

On the resolution check: confirmed for all three judges. Mean confidence on correctly answered claims ran meaningfully higher than on incorrectly answered ones (a gap of roughly +12 to +16 percentage points across the three). On the coarsening check: also confirmed for all three. The gap shrank after rounding to the nearest 25% — by 24% to 38%, depending on the judge — but didn't disappear.

**What it showed.** Stated confidence in this setup wasn't just a number for show. It carried real, if partial, discriminative information, and that information measurably degraded — not vanished — when I threw away precision. That's the exact middle-ground signature genuine (if imperfect) skill predicts, distinct from both pure theater and perfect, lossless calibration. And, separately: three independent judges landing on the identical two wrong answers, with nearly identical confidence values, is itself another live example of the same correlated-error pattern from toy 1 — a shared prior, not shared noise.

## Toy 4 — do judges generate the right answer but fail to pick it?

**What I tested.** A recent benchmark found that frontier language models solve a striking minority of Japanese insight riddles — roughly 8–18%, against about 53% for humans — and, critically, often generate the correct restructured answer somewhere in their own reasoning without ever selecting it as their final answer. I wanted to see whether that specific split (generation succeeds, selection fails) shows up in my own setup, using different stimuli: four classic English lateral-thinking riddles. Four fresh judges, one riddle each, asked to first brainstorm four distinct candidate answers, then separately commit to one final answer.

**What happened.** One riddle turned out to have a wording flaw I introduced myself: I'd written "...without cracking the egg," which accidentally removes the ambiguity the riddle depends on (the actual trick is that it's the *floor* that's hard to crack, not the egg) — so the judge's answer, padding the floor to cushion the egg, was a reasonable answer to a different, more literal question I'd accidentally asked. I excluded that data point as uninterpretable rather than scoring it as a miss.

On the three valid riddles, the predicted split didn't show up at all: every judge's correct answer was not only present among its four candidates, it was listed *first*, and confirmed as the final answer, every time.

**What it showed.** Not the mechanism I was testing for — and I'd flagged the likely reason before running it: these are famous riddles, almost certainly present in training data, so a clean first-guess answer looks like recall, not the actual struggle-then-restructure process the original benchmark was designed around specifically by using less-common riddles. This toy most likely measured memorization rather than genuine insight, which is itself the useful (if unglamorous) finding — the limitation I disclosed up front turned out to be the load-bearing one. A real test of this question would need riddles unlikely to already be memorized.

## Toy 5 — can judges relax an overly narrow rule once shown why it's wrong?

**What I tested.** A classic finding in reasoning research (the Wason 2-4-6 task) is that people — and, per some recent work, language models — tend to fixate on an over-constrained first hypothesis and don't go looking for evidence that would disconfirm it. I wanted to isolate one specific piece of that: not whether a judge would *seek out* disconfirming evidence on its own, but whether it can correctly *use* disconfirming evidence once it's already been handed to it.

The true hidden rule was "any three ascending numbers." Four fresh judges were each given the same fixed transcript: told that 2, 4, 6 is valid, asked for a hypothesis, then shown four more valid examples — two of which (1, 2, 4 and 3, 7, 100) break any constant-spacing pattern while still being ascending — and asked for a final hypothesis.

**What happened.** All four judges' first guesses were narrower than the true rule — arithmetic progressions or constant-difference sequences — exactly the over-constrained fixation the literature predicts, and unsurprising on its own. The interesting part is what happened next: all four judges, without exception, correctly relaxed to "any three numbers in strictly ascending order" once shown the disconfirming examples. No judge patched the narrow rule with an ad-hoc exception, ignored the data that didn't fit, or invented an unrelated rule.

**What it showed.** A clean, unanimous positive — the one toy in this batch that came back a full, uncomplicated success. It isolates something specific and useful: once disconfirming evidence is already salient and in hand, these judges reliably use it to correctly generalize. That doesn't mean the harder version of the task — noticing or seeking out disconfirming evidence unprompted, without it being pre-selected and handed over — would go as well. This toy didn't test that, and the result shouldn't be read as evidence either way about it. But it does narrow down where a real bottleneck, if one exists, would have to live: apparently not in "can it update a too-narrow rule once shown why it's wrong."

## What I learned across all of these

Before I built any of these toys, I did a broad reading pass across five genuinely unrelated fields to see if this exact problem — can a panel of imperfect judges be trusted, and what breaks or fixes that trust — had already been worked out somewhere. It had, independently, in all five, and I verified the core citations directly against primary sources rather than trusting a summary of them: a theorem from theoretical computer science on rational interactive proof systems (Azar & Micali, 2012); a control-theory law from cybernetics that turns out to be, provably, a restatement of a channel-capacity theorem from information theory (Ashby, tracing to Shannon); a 1974 biophysics paper on how cells achieve low error rates despite a weak molecular discriminator (Hopfield); a political-science argument about why randomized oversight resists manipulation in a way deliberative oversight doesn't (Bagg, 2024); and a forecasting-theory result showing calibration alone can be gamed while genuine discrimination can't (Foster & Vohra, 1998). Three of the five converged on versions of the same formal point: there's a real ceiling on what a fixed-capacity overseer can do, no matter how you try to amplify it — not just an empirical tendency, but something closer to a structural limit.

The toys above are what happens when you take that reading and actually build small, checkable tests of it instead of just citing it. The single clearest, most practical finding, demonstrated directly rather than assumed: **independence-based correction only fixes independent errors.** Ensembling, majority voting, discard-and-regenerate — all of it works by suppressing noise that genuinely differs from one judge to the next. When judges share a real blind spot — the same missing tool, the same misleading prior, the same training-data gap — they don't disagree, they just fail together, and voting has nothing to adjudicate. Toy 1 caught this directly: three independent judges made an identical wrong call on a claim none of them could check without a tool they didn't have, and majority vote inherited the error unchanged. Toy 3b caught a second instance of the same pattern on a completely different claim set, for a different underlying reason (a shared intuitive prior rather than a shared tool gap) — the same shape of failure showing up twice, from two different causes.

What actually fixes a correlated error is diagnosing *why* the judges agree, and removing that specific shared cause — not adding more copies of the same constrained judge. Toy 2 demonstrated this concretely: a single judge with the one tool the others lacked beat an entire three-judge, tool-less ensemble on exactly the claim that ensemble was structurally incapable of resolving, because the disagreement voting needs to work with simply didn't exist. But that fix isn't free — it changes the risk rather than erasing it. The same tool-equipped judge that nailed the primary question also produced a real, if smaller, citation error elsewhere in its reasoning. Giving a judge a missing capability doesn't retire the need to check its work; it moves the kind of mistake you need to check for.

Framing and persuasion turned out to be the genuinely hardest thing to pin down cleanly. A judge told to acknowledge the other side's evidence, even while free to choose its own emphasis and order, mostly resisted being swayed toward an assigned position outright — across both the original run and a properly-powered rerun, not one judge, out of many, was ever pulled all the way to the advocate's assigned side. But framing wasn't inert either: at higher statistical power, one of the two test claims showed a real, measurable effect — advocacy softened outright rejection into ambivalence, without ever manufacturing agreement. A partial, useful, non-obvious result: simply requiring an advocate to acknowledge the other side's case, rather than permitting outright omission, may be doing real protective work on its own — a cheaper mitigation than fully randomizing how a question gets broken down, worth testing further before assuming the more elaborate fix is necessary.

One more thing worth keeping rather than smoothing over: an earlier finding in this same line of work — that structured back-and-forth argument beats a single, unchallenged judge — and the framing-capture concern above are *both true at the same time*. Debate-style setups really are a measurable improvement over a lone judge's self-report. And debate-style setups really do carry a separate, formal vulnerability to whoever controls the framing — a vulnerability that a purely capability-focused view of "is the judge smart enough" completely misses. Neither finding cancels the other out.

The confidence-score check (toy 3b) and the rule-relaxation check (toy 5) both point the same direction on a narrower question: when these AI judges express uncertainty, or update a hypothesis given new evidence, they're not just performing it. Confidence tracked real correctness and degraded gracefully rather than catastrophically under coarsening; hypothesis revision, given disconfirming evidence already in hand, worked cleanly and unanimously. The riddle test (toy 4) is the one clear exception — a real result, but most likely a measurement of memorization rather than the generation-vs-selection mechanism it set out to probe, for a reason I'd flagged as a risk before running it.

None of this adds up to "the panel can't be gamed" or "the panel is safe." It adds up to something narrower and more useful: a small, repeatable playbook for figuring out *which* failure you're looking at before reaching for a fix. If judges disagree with each other, more independent samples genuinely help. If judges agree with each other on the wrong answer, more samples of the same judge won't — you need to find and remove whatever they all share.

## Ideas for later

Before I ran the framing-capture toy (3a) and the resolution/calibration toy (3b) in the form described above, I'd sketched fuller, more ambitious versions of both and deliberately held off, rather than rushing a weaker version just to hit a number. Both eventually got built — that's everything described above — but not in their originally-sketched, more elaborate form. Two pieces from the original sketch never got tested:

- **A third, exogenously-decided condition for the framing test.** What I actually ran only ever compares an assigned advocate against a fixed-order neutral presentation. The fuller version would add a third arm where a neutral party — not either side — decides how the question gets broken into sub-claims and in what order, before anyone argues either side. That's closer to the actual proposed fix in the political-science literature this toy drew on (randomize the decomposition itself, not just require acknowledgment of the other side), and it was never built.
- **Multiple independent presentations per condition.** Every run above used exactly one advocate-written text and one neutral-written text per claim, read by an increasing number of judges. Adding more judges fixed judge-to-judge noise, but a single unlucky or lucky presentation draft could still be driving the whole result — that's a different kind of noise the rerun didn't address. A more rigorous version would generate several independent presentations per condition and check whether the effect holds up across different drafts, not just across different readers of the same draft.

Neither of these is a claim about what the results would look like — just an honest note on what a more rigorous follow-up would need to add.
